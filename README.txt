
这是一款基于UE及其Steam网络插件实现的软件，简介与使用步骤如下：

简介：
	一款第一人称FPS游戏，初始有两种武器：手枪与步枪，每名玩家共有150滴血量
	手枪每枪将造成：100滴伤害。
	步枪每枪将造成：15滴伤害，以及后续5秒每半秒扣除3滴共30滴的后续伤害。
	地图中将有旋转的枪械模型以供补充弹药，仅有步枪弹药提供

按键：
	鼠标左键开火，右键瞄准。
	键盘E为切换枪械，R为换弹，空格为跳跃，C为蹲下

准备步骤：
	开启并登录Steam，在设置中点击下载，修改下载中的下载地区region，将你与你朋友的地区修改为一致，即可开始游戏。
	两个或以上玩家进入游戏后房主使用键盘上Enter键，开始游戏

UI界面介绍：
- 进入游戏后将选择作为主机或是客户端加入，Host为作为主机，Join为作为客户端。
- 房主可以在Number of Players中输入玩家上线（默认为4），输入非数字数据将无效
- 房主可在 Number of Players 上端选择 Capture the Flag、Free For All、Teams三种房间类型。该选择会作为房间标签（MatchType）随房间一起发布。
	- 三种类型在功能上完全对等，都是"房间标签"，不改变血量、武器、伤害等任何玩法规则。唯一的实际作用是配对：客户端点 Join 时，只加入标签与自己勾选类型相同的房间，只要未达到人数限制，就可以进入。
	- 选错类型会一直匹配不到房间，可重选后再次点击Join 按钮搜索房间。
	- 房主与客户端请务必勾选同一类型，否则双方互相无法搜索、无法进入对方的房间。
- 右上角Quit可以退出
