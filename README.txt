# 游戏简介与使用说明

> 基于 UE 及 Steam 网络插件实现的第一人称 FPS 游戏。

## 一、简介

- 第一人称 FPS 游戏，初始有两种武器：**手枪** 与 **步枪**。
- 每名玩家共有 **150 滴血量**。

| 武器 | 单发伤害 | 后续伤害 |
| --- | --- | --- |
| 手枪 | 100 | 无 |
| 步枪 | 15 | 命中后 5 秒内每半秒扣 3 滴，共 30 滴 |

- 地图中将有 **旋转的枪械模型** 以供补充弹药，仅有步枪弹药提供。

## 二、按键操作

| 按键 | 功能 |
| --- | --- |
| 鼠标左键 | 开火 |
| 鼠标右键 | 瞄准 |
| E | 切换枪械 |
| R | 换弹 |
| 空格 | 跳跃 |
| C | 蹲下 |

## 三、准备步骤

1. 开启并登录 Steam。
2. 在「设置 → 下载」中修改下载地区 `region`，将你与朋友的地区修改为一致，即可开始游戏。
3. 两个或以上玩家进入游戏后，房主使用键盘上的 `Enter` 键开始游戏。

## 四、UI 界面介绍

- 进入游戏后将选择作为主机或客户端加入：`Host` 为作为主机，`Join` 为作为客户端。
- 房主可以在 `Number of Players` 中输入玩家上限（默认为 4）；输入非数字数据将无效。
- 房主可在 `Number of Players` 上端选择 `Capture the Flag`、`Free For All`、`Teams` 三种房间类型。该选择会作为房间标签（`MatchType`）随房间一起发布。
    - 三种类型在功能上完全对等，都是「房间标签」，不改变血量、武器、伤害等任何玩法规则。唯一的实际作用是配对：客户端点 `Join` 时，只加入标签与自己勾选类型相同的房间，只要未达到人数限制，就可以进入。
    - 选错类型会一直匹配不到房间，可重选后再次点击 `Join` 按钮搜索房间。
    - 房主与客户端请务必勾选同一类型，否则双方互相无法搜索、无法进入对方的房间。
- 右上角 `Quit` 可以退出。
